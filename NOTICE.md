# Third-party assets

None. Every visual in this project is generated by its own code:

- **Hero helmet** — `components/hero/HelmetModel.tsx` builds a full-face road
  helmet from three.js geometry (revolved shell, eyeport, smoked visor, chin
  bar, vents). No downloaded model, so there is no licence to honour and
  nothing to replace before going live. Proportions are tunable in that
  file's `DIMS`.
- **Product imagery** — `components/HelmetArt.tsx` draws a vector helmet
  tinted with each product's colour, and renders whenever a product's
  `images` array is empty. Real photography replaces it by filling `images`
  in the data layer; the components already prefer a photo when one exists.
  Remote hosts must be added to `images.remotePatterns` in `next.config.ts`
  at that point.
